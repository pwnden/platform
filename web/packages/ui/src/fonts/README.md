The player serves these fonts locally. It makes no external font requests.

- Pretendard Variable 1.3.9 (body and controls): [upstream](https://github.com/orioncactus/pretendard/blob/5c41199ea0024a9e0b2cb31735265056e5472d76/packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2), revision `5c41199ea0024a9e0b2cb31735265056e5472d76`. License: `Pretendard-OFL.txt`.

- JetBrains Mono Regular and Medium: [upstream](https://github.com/JetBrains/JetBrainsMono/tree/19371302b95d218af43299bce79ddbddd0bc364d/fonts/webfonts), revision `19371302b95d218af43299bce79ddbddd0bc364d`. License: `JetBrainsMono-OFL.txt`.
- D2Coding Regular: [upstream](https://github.com/naver/d2-coding-font/blob/9d6f0559691ebe670a23fbf7b72a8dc42362f1fb/site/fonts/D2Coding-Regular.woff2), revision `9d6f0559691ebe670a23fbf7b72a8dc42362f1fb`. License: `D2Coding-OFL.txt`.

JetBrains Mono renders Latin text; D2Coding supplies Korean monospace glyphs.
